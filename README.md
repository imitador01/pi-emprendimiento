# Café Campus · Pedidos anticipados

Aplicación web para pedidos de tienda universitaria con flujo de selección, carrito, confirmación y WhatsApp.

## Requisitos

- Node.js 18+
- npm

## Ejecutar localmente

```bash
npm install
npm start
```

Luego abre http://localhost:3000

## Variables de entorno

- `PORT`: puerto del servidor (por defecto 3000)
- `WHATSAPP_NUMBER`: número del negocio para abrir un chat de WhatsApp

Ejemplo:

```bash
WHATSAPP_NUMBER='+57 3137586609' npm start
```
